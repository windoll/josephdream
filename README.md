## 🎮 玩法

你扮演約瑟,走過他的一生。每一幕做一個選擇,選擇會改變你的三種屬性:

| 屬性 | 代表 |
|------|------|
| **信心** | 在壓力下的定力與對神的信靠 |
| **智慧** | 看穿局勢、應變、解夢的才智 |
| **野心** | 往上爬的企圖心與世俗影響力 |

你怎麼選,就會長成什麼樣的人——而那會決定你走向哪一個結局。

### 讓選擇有重量的三個機制(全程無隨機,你選的路就是你的路)

- ⚖️ **取捨**:走捷徑攀權會 `+野心 −信心`。想要權力,就得犧牲別的。
- 🌱 **隱藏解鎖**:有些路,要長成那樣的人才看得見——智慧夠高,曠野裡會多出一條逃跑的路;野心夠大,法老面前能開出別人不敢開的條件。
- 🔒 **一個揪心的鎖**:哥哥跪在腳前那一刻,「直接原諒」需要足夠的信心——若你還沒真正平靜下來,那扇門是鎖著的。
- 🌿 **真分岔**:不同走法會走進不一樣的場景(例如「智取主母」「亡命曠野」),不是換句話而已。

## 🏆 七種結局

每個結局都有一個「**你是哪一型的約瑟**」標籤,玩完可以跟朋友比比看。

| 結局 | 類型 | 怎麼走到 |
|------|------|---------|
| ★ 飽足之地 📖 | 和好型 | 信心與智慧都夠高、不被野心主導(**最圓滿,也最需要均衡經營**) |
| ★ 夢的應驗 | 堅信型 | 信心一路最高 |
| ★ 萬民的拯救者 | 智略型 | 智慧一路最高 |
| ◇ 埃及的權臣 | 雄心型 | 野心一路最高(位極人臣,卻有點空) |
| ◇ 平凡的牧人 | 安穩型 | 在法老面前婉拒呼召,回家當普通人 |
| ☠ 墜落 | 失足型 | 在波提乏家屈服於試探 |
| ☠ 復仇的筵席 | 復仇型 | 在哥哥跪下時選擇報復 |

> 📖 標記代表「符合聖經記載」的選項與結局。經文出處淡化為背景,故事為主——適合青少年自己玩,也適合主日學、青年團契、親子共讀。
