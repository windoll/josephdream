## 🎮 玩法

你扮演約瑟,走過他的一生。每一幕做一個選擇,選擇會改變你的三種屬性:

| 屬性 | 代表 |
|------|------|
| **信心** | 在壓力下的定力與對神的信靠 |
| **智慧** | 看穿局勢、應變、解夢的才智 |
| **認同** | 被看見、被記得的渴望——把自己交給別人的眼光 |

你怎麼選,就會長成什麼樣的人——而那會決定你走向哪一個結局。

### 讓選擇有重量的機制(全程無隨機)

- 📖 **一條聖經路線**:全遊戲只有一條完全跟著聖經走的路,通往唯一的「📖🏁 聖經結局」;其餘每一個結局,都是一個「**如果約瑟當時……**」的 What-if。
- 🚪 **支線裡藏著回頭的門**:逃跑、屈服、造神、報復,都會把故事往岔路推一段——在支線的盡頭,一邊是沉下去的結局,另一邊,是一扇**回主線的門**。走錯路,不等於故事結束。(報復路上那扇「鬆手」的門,正是創世記 42 章真實發生的事。)
- 🔑 **屬性是鑰匙**:有些門,要長成那樣的人才推得開——數值不夠的選項會鎖住給你看。智慧開「逃跑」的門,認同開「造神」的門,信心開「頂樓的夜禱」——察驗之前,先把二十年的帳,攤在神面前。
- 🗝 **你做過的事,也是鑰匙**:終幕「報復」的門,只對第一幕在曠野裡選了「記住今天」的人打開——十秒的小決定,在四十分鐘後決定你能不能走進深淵。
- 🗺 **路線圖**:像《底特律:變人》那樣攤開整張流程圖——走過的路點亮,沒走過的顯示 `???`,鎖著的門連鑰匙都標給你看。重玩的理由,地圖自己會長出來。
- ⚖️ **取捨**:想被更大的人物看見,要付代價(`+認同 −信心`)。掌聲與交託,難以兩全。
- 💬 **微回應**:每個選擇都會在下一幕開頭被「看見」一句——你的選擇,故事記得。

## 🏆 七種結局

每個結局都有一個「**你是哪一型的約瑟**」標籤,玩完可以跟朋友比比看。

一條聖經結局,六個「如果約瑟當時……」——每個結局,都有自己專屬的一條路。

| 結局 | 類型 | 在哪裡走上這條路 |
|------|------|---------|
| ★ 飽足之地 📖 | 和好型 | **唯一的聖經結局**:一路跟著 📖 的腳蹤走到底 |
| ◇ 逃走的人 | 自保型 | 逃出曠野後,一路往北——走到沒有人認識你的地方 |
| ☠ 墜落 | 失足型 | 越了線之後,選擇繼續瞞下去 |
| ◇ 平凡的牧人 | 安穩型 | 在法老面前婉拒呼召,回家當普通人 |
| ◇ 萬人的掌聲 | 人望型 | 哥哥跪在萬人中那天,把臉藏回宰相的妝底下 |
| ☠ 復仇的筵席 | 復仇型 | 聽完牢裡的認罪,仍讓報應走完(這扇門,只對記恨過的人開) |
| ◇ 無名的恩人 | 隱忍型 | 供應他們一切,卻永遠不說出自己是誰 |

> 📖 標記代表「符合聖經記載」的選項與結局。經文出處淡化為背景,故事為主——適合青少年自己玩,也適合主日學、青年團契、親子共讀。
