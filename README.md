## 🎮 玩法

你扮演約瑟,走過他的一生。每一幕做一個選擇,選擇會改變你的三種屬性:

| 屬性 | 代表 |
|------|------|
| **信心** | 在壓力下的定力與對神的信靠 |
| **智慧** | 看穿局勢、應變、解夢的才智 |
| **認同** | 被看見、被記得的渴望——把自己交給別人的眼光 |

你怎麼選,就會長成什麼樣的人——而那會決定你走向哪一個結局。

### 讓選擇有重量的機制(全程無隨機)

- 🌿 **岔出去,再接回來**:五個關鍵抉擇各通往三條不同的小故事(夜禱/全家的怒火、駝背上的學徒、內廷的線、被遺忘的兩年、全地歸法老……),走完才合回聖經主線——你選的路,真的會發生不一樣的事。
- ⚖️ **取捨**:想被更大的人物看見,要付代價(`+認同 −信心`)。掌聲與交託,難以兩全。
- 🔒 **屬性門檻**:有些路,要長成那樣的人才能走——數值不夠的選項會鎖住給你看(「需要認同 40,目前 20——你還不懂得,怎麼讓人看上你」)。最揪心的一個在終幕:「直接原諒」需要足夠的信心。
- 🏁 **結局標籤**:離開主線的出口標暗紅「🏁 結局」;通往聖經記載結局的路,標金色「📖🏁 聖經結局」。
- 💬 **微回應**:每個選擇都會在下一幕開頭被「看見」一句——你的選擇,故事記得。

## 🏆 七種結局

每個結局都有一個「**你是哪一型的約瑟**」標籤,玩完可以跟朋友比比看。

| 結局 | 類型 | 怎麼走到 |
|------|------|---------|
| ★ 飽足之地 📖 | 和好型 | 信心與智慧都夠高、不被掌聲牽著走(**最圓滿,也最需要均衡經營**) |
| ★ 夢的應驗 | 堅信型 | 信心一路最高 |
| ★ 萬民的拯救者 | 智略型 | 智慧一路最高 |
| ◇ 萬人的掌聲 | 人望型 | 認同一路最高(全埃及都仰望你,可是掌聲散場之後呢?) |
| ◇ 平凡的牧人 | 安穩型 | 在法老面前婉拒呼召,回家當普通人 |
| ☠ 墜落 | 失足型 | 在波提乏家屈服於試探 |
| ☠ 復仇的筵席 | 復仇型 | 在哥哥跪下時選擇報復 |

> 📖 標記代表「符合聖經記載」的選項與結局。經文出處淡化為背景,故事為主——適合青少年自己玩,也適合主日學、青年團契、親子共讀。
