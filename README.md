# 約瑟的夢 — 文字冒險遊戲

以聖經《創世記》約瑟的故事為基底的網頁文字冒險遊戲,具備 **What-if 分支劇情** 與 **多重結局**。

## 特色

- 📖 完整改編約瑟的一生(創世記 37–50 章)
- 🔀 每個關鍵抉擇都有「忠於原著」與「What-if 假設」兩種走向
- 🏆 **11 種結局**(美好 / 中性 / 悲劇),含隱藏結局
- ⚖️ 隱藏數值系統:**信心 / 智慧 / 怨恨**,影響後續分支與最終結局
- 🎨 內嵌 SVG 場景插畫(離線可用,無需額外圖檔)
- 💾 自動存檔進度 + 結局圖鑑

## 遊玩方式

直接用瀏覽器打開 `index.html`(或 `約瑟的夢.html`)即可遊玩。

無需安裝任何環境,單一 HTML 檔。

## 技術

純 HTML + CSS + JavaScript,無外部相依套件。
