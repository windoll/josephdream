# 約瑟的夢 — 十七歲的抉擇

以聖經《創世記》約瑟的故事為基底、**為青少年設計**的網頁文字冒險遊戲。約瑟被賣時才十七歲——被手足排擠、面對誘惑、被冤枉、最後要不要報復傷害他的人。每個抉擇,都真的有後果。

## 特色

- 📖 改編約瑟的一生(創世記 37–50 章),語氣貼近青少年
- 🔀 每個抉擇對應 **信心 / 智慧 / 野心** 三種屬性
- ⚖️ **取捨**:攀權往上爬要付代價(`+野心 −信心`),夢想與正直難兩全
- 🎲 **風險賭注**:逃跑成不成,看你的智慧——但永遠有輸面
- 🔒 **屬性門檻**:練到夠強才解鎖更大膽的選項
- 🌿 **真分岔**:不同走法走進不一樣的場景,提高重玩價值
- 🏆 **7 種結局**,各有可分享的「你是哪一型的約瑟」標籤;最圓滿的「飽足之地」需要均衡經營才拿得到
- 📖 符合聖經記載的選項會標示 📖;每幕標註真實章節出處(經文淡化為背景)
- 📜 結局後「你的旅程」回顧 + 一句「想一想」
- 🎨 內嵌 SVG 場景插畫(離線可用,無需額外圖檔)
- 💾 自動存檔進度 + 結局圖鑑

## 遊玩方式

直接用瀏覽器打開 `index.html` 即可遊玩。

無需安裝任何環境,單一 HTML 檔。

## 技術

純 HTML + CSS + JavaScript,無外部相依套件。
