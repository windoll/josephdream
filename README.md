# 約瑟的夢 — 文字冒險遊戲

以聖經《創世記》約瑟的故事為基底的網頁文字冒險遊戲,具備 **What-if 分支劇情** 與 **多重結局**。

## 特色

- 📖 完整改編約瑟的一生(創世記 37–50 章)
- 🔀 每個抉擇都是三選一,分別對應 **信心 / 智慧 / 怨恨** 三種屬性
- 🏆 **5 種結局**(美好 2 / 中性 1 / 悲劇 2),含隱藏結局「夢的應驗」
- 📖 **聖經原典提示**:符合聖經記載的選項與真實結局都會標示出來
- 🌿 **獨家支線**:不同屬性傾向會解鎖不一樣的劇情場景,增加重玩價值
- ⚖️ 數值系統:你的選擇會累積屬性,最終決定走向哪一個結局
- ⌨️ 打字機文字效果、屬性變化動畫、Web Audio 音效(可靜音)
- 📜 結局後「你的旅程」回顧 + 反思問題,適合主日學/親子共讀
- 📕 每幕標註真實聖經章節出處
- 🎨 內嵌 SVG 場景插畫(離線可用,無需額外圖檔)
- 💾 自動存檔進度 + 結局圖鑑

## 遊玩方式

直接用瀏覽器打開 `index.html` 即可遊玩。

無需安裝任何環境,單一 HTML 檔。

## 技術

純 HTML + CSS + JavaScript,無外部相依套件。
